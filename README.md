# 사장님AI

소상공인이 가게·메뉴·상품 사진 한 장으로 SNS 광고 소재를 빠르게 만드는 AI 광고 제작 MVP입니다.

## 현재 구현
- OpenAI 기반 광고 제목·본문·해시태그 생성
- 업로드 사진 기반 광고 비주얼 3종 생성: 감성형 / 제품 강조형 / 홍보형
- 인스타 피드 1:1, 스토리 9:16, 4:3 규격 재배치
- 가게명·가격·혜택·기간·연락처·브랜드 색상·로고 오버레이
- PNG 개별 저장 및 3장 일괄 저장
- 브라우저 로컬 가게 프로필 저장
- Upstash KV 기반 네트워크별 무료 체험 1회 제한
- Vercel Firewall 요청 속도 제한과 서버 측 동시 생성 방지

## 운영 구조
Frontend: `index.html`  
Text API: `/api/generate`  
Image API: `/api/generate-image`  
Hosting/API: Vercel  
Trial state: Upstash Redis/KV

이미지 API는 무료 체험 요청을 먼저 서버에서 선점한 뒤 OpenAI를 호출합니다. 생성 실패 시 선점을 해제하고, 성공하면 사용 완료 상태로 변경합니다. 원본 IP 주소는 KV 키에 그대로 저장하지 않습니다.

## 필요한 환경 변수
- `OPENAI_API_KEY`
- `KV_REST_API_URL`
- `KV_REST_API_TOKEN`

비밀 값은 저장소에 커밋하지 않습니다.

## 현재 MVP 제한
- 결제 기능 미연결
- 계정/로그인 없음
- 무료 체험은 계정이 아닌 네트워크 식별 기준이라 공유 Wi-Fi·VPN 환경에서는 정확한 사용자 단위 판별이 불가능
- 유료 요금제와 가격은 검증 전 예시
- 숏폼 생성은 아직 미구현

## 검증 완료
- 실제 Vercel 배포 환경에서 첫 무료 광고 생성 성공
- 광고 이미지 3종 생성 확인
- 같은 네트워크의 두 번째 무료 생성 서버 차단 확인

## MVP 완료 기준
현재 버전은 무료 베타 MVP로 고정합니다. 핵심 생성·저장·무료체험 비용 방어가 실제 배포 환경에서 검증됐습니다. 유료 기능을 억지로 추가하기보다 다음 단계에서는 사용자 반응과 결과 품질을 먼저 확인합니다.

## 다음 제품 단계
1. 카페·음식점·미용실·헬스장·쇼핑몰 등 다양한 업종으로 결과 품질 검증
2. 테스트 사용자 피드백 수집 및 반복되는 불편 수정
3. 유료 전환 근거가 생기면 결제/크레딧 시스템 구현
4. 이후 계정 기반 사용량·브랜드 프로필 서버 저장
5. 수요가 확인된 뒤 숏폼 광고 확장


## 테스트 체크리스트
- 필수 입력값이 없을 때 API 호출 전에 안내되는지 확인
- JPG/PNG/WEBP 이외 파일이 차단되는지 확인
- 3.5MB 초과 광고 사진과 2MB 초과 로고가 차단되는지 확인
- 첫 무료 생성에서 광고 3종과 SNS 문구가 표시되는지 확인
- 같은 네트워크의 두 번째 무료 이미지 생성이 서버에서 차단되는지 확인
- 1:1 / 9:16 / 4:3 전환이 추가 AI 호출 없이 동작하는지 확인
- 개별 PNG와 3장 일괄 저장이 동작하는지 확인
- 가게 프로필 저장/초기화가 브라우저에서 정상 동작하는지 확인
- 클립보드 권한이 없을 때 대체 안내가 표시되는지 확인

## 출시 전 필수 작업
- 실제 유료 결제 전 사업/결제 요건 확인 및 결제·크레딧 원장 구현
- 계정 도입 시 개인정보 처리방침과 데이터 보관/삭제 정책 정리
- 실제 사용자 피드백을 서버로 수집할 경우 별도 동의·보관 정책 마련
- 다양한 업종·사진에서 결과 품질과 실패율 측정
